# Candidates

Staging area for ideas found while scouting. **Nothing in this file is curriculum yet.** A candidate becomes a lesson only when the learner accepts it (see `prompts/SCOUT.md` and `AGENTS.md`).

Keeping the history here, including skipped ideas, stops future sessions from proposing the same things again.

## Format

One entry per candidate, newest first:

```markdown
### <Concept name>
- **Source:** <title or repository> — <URL>
- **What the source is/does:** <one or two factual sentences>
- **Transferable concept:** <the idea a lesson would teach>
- **Relation to existing lessons:** <none / deepens course-slug/NN / overlaps course-slug/NN>
- **Outcome:** PROPOSED | ADD → course-slug/NN | MERGE → course-slug/NN | REFERENCE | REPLACE → course-slug/NN | SKIP
- **Notes:** <evidence quality, why this outcome, date>
```

`PROPOSED` means the idea is waiting for the learner's decision.
